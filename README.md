# MathSurfers

**MathSurfers** is an educational endless runner game designed to make learning basic math skills fun and engaging. Players solve simple arithmetic tasks while avoiding obstacles and collecting points to advance through the game.  

The project is developed in **Unity**, featuring both a **standard 3D mode** and a **VR mode** compatible with **Oculus Quest 2**.  

> ⚠️ This project is currently in an **early development stage**. Some features may be missing, unstable, or not yet implemented. Certain Unity packages and extensions used in earlier versions may no longer be compatible with the latest Unity releases. A future update is planned to **migrate the project to a newer Unity version** and improve overall performance and stability.
